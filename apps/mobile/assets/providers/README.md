# Identity-provider artwork

`google.png` is Google's unmodified color mark downloaded from
https://developers.google.com/static/identity/images/g-logo.png and used only
with the Google sign-in action. Render with `contain` to preserve its proportions.
Brand guidance: https://developers.google.com/identity/branding-guidelines.

The Apple mark for browser/Android buttons is defined once in
`packages/shared/src/auth/providerArtwork.ts`, sourced from Apple's public web
SDK. iOS continues to render Apple's native authentication button.
